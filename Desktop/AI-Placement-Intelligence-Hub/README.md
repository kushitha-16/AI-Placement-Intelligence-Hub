# AI Placement Intelligence Hub

AI-powered placement assistant that analyzes placement posts from Telegram, WhatsApp, email, or job descriptions.

## Features

- Paste placement post
- Extract company name, role, eligibility, required skills, deadline, selection rounds, and apply link
- Store job post in MySQL database
- React frontend for simple demo

## Tech Stack

- Frontend: React.js + Vite
- Backend: Java Spring Boot
- Database: MySQL
- Future AI: Gemini API

## Project Modules

1. Placement Post Analyzer
2. Resume-to-Job Matcher
3. Skill Gap Analyzer
4. Personal Study Planner
5. Placement Tracker Dashboard
